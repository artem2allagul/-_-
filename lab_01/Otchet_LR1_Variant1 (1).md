## 2. Краткие теоретические сведения

Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной. Переменные представляют собой ссылки (имена), связанные с объектами в динамической памяти. Отступы (ровно 4 пробела) обязательны и служат для группировки блоков кода.

Метод `format()` позволяет выполнять форматирование в соответствии со спецификацией PEP 3101. Например, выражение `'{0:.3f}'.format(pi)` форматирует вещественное число с точностью до трёх знаков после запятой. Вместо метода `format()` в данной работе используются f-строки, обеспечивающие более компактную и читаемую запись форматированного вывода.

Функция `input()` используется для ввода исходных данных с клавиатуры и всегда возвращает значение строкового типа, поэтому для дальнейших вычислений строка приводится к вещественному типу с помощью функции `float()`.

## 3. Задание (Вариант №1)

Написать скрипт, вычисляющий силу гравитационного притяжения между двумя телами по закону всемирного тяготения Ньютона:

**F = G · (m1 · m2) / r²**

где G — гравитационная постоянная, m1 и m2 — массы взаимодействующих тел, r — расстояние между их центрами масс.

Все переменные должны быть динамически привязаны к значениям (введены пользователем). Исходные параметры ввести с помощью функции `input()`. Результат вывести с округлением вещественной части до 4 знаков после запятой.

| Параметр | Значение |
|---|---|
| G (гравитационная постоянная) | 6.674 · 10⁻¹¹ Н·м²/кг² |
| m1 (масса первого тела) | 5.97 · 10²⁴ кг |
| m2 (масса второго тела) | 7.34 · 10²² кг |
| r (расстояние между телами) | 3.84 · 10⁸ м |

## 4. Исходный код программы

*Файл: `variant1.py`*

```python
# variant1.py
# Лабораторная работа №1. Вариант 1.
# Вычисление силы гравитационного притяжения по закону всемирного тяготения Ньютона
# Формула: F = G * (m1 * m2) / r^2

# Ввод исходных данных с клавиатуры с помощью функции input()
# Строковые значения сразу преобразуются в вещественный тип float()
G = float(input('Введите гравитационную постоянную G (Н*м^2/кг^2): '))
m1 = float(input('Введите массу первого тела m1 (кг): '))
m2 = float(input('Введите массу второго тела m2 (кг): '))
r = float(input('Введите расстояние между телами r (м): '))

# Расчет силы гравитационного притяжения
# Степень записывается оператором ** (а не ^, как в математической записи)
F = G * (m1 * m2) / r ** 2

# Вывод результата с округлением вещественной части до 4 знаков после запятой
# с помощью f-строки и спецификатора формата {:.4f}
print(f'Сила гравитационного притяжения F = {F:.4f} Н')
```

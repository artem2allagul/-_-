## 1. Цель работы

Изучение синтаксиса и практических возможностей условных операторов (`if-elif-else`), циклических конструкций (`while`, `for..in`) и пользовательских функций (`def`) в языке Python. Приобретение навыков декомпозиции алгоритмов управления, передачи аргументов и возврата результатов вычислений.

## 2. Краткие теоретические сведения

**Условный оператор `if-elif-else`:** используется для проверки логических условий и ветвления алгоритма. Конструкция `elif` позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок `else` выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (`:`) и строгое соблюдение отступов (4 пробела).

**Цикл `while`:** выполняет блок выражений до тех пор, пока проверяемое условие истинно (`True`). Для экстренного выхода из цикла применяется оператор `break`, а для перехода к следующей итерации — `continue`. При естественном завершении цикла выполняются команды из необязательного блока `else`.

**Цикл `for..in` и функция `range()`:** осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция `range(start, stop, step)` генерирует арифметическую прогрессию чисел, не включая верхнюю границу `stop`.

**Пользовательские функции (`def`):** представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова `def`, принимает параметры и возвращает результаты вычислений оператором `return`. Строки документации docstrings (в тройных кавычках) размещаются сразу после заголовка функции для описания её назначения.

## 3. Задание (Вариант №1)

Разработать функцию `analyze_reactor(temperatures, norm_temp=100, max_temp=180)`, которая принимает список замеров температуры. В цикле анализировать значения: T < 100 °C — «Нагрев», 100..180 °C — «Норма», T > 180 °C — «Авария». Функция должна возвращать кортеж из средней температуры и количества аварийных замеров.

## 4. Исходный код программы

```python
def analyze_reactor(temperatures, norm_temp=100, max_temp=180):
    total_temp = 0
    emergency_count = 0
    count = len(temperatures)

    if count == 0:
        return 0.0, 0

    print("Результаты анализа замеров")
    for t in temperatures:
        total_temp += t
        if t < norm_temp:
            print(f"Температура {t} С - Нагрев")
        elif norm_temp <= t <= max_temp:
            print(f"Температура {t} С - Норма")
        else:
            print(f"Температура {t} С - Авария")
            emergency_count += 1

    avg_temp = total_temp / count
    return avg_temp, emergency_count


measurements = [85.5, 100.0, 120.3, 185.0, 95.0, 200.5]
avg, emergencies = analyze_reactor(measurements)
print("-" * 34)
print(f"Средняя температура: {avg:.2f} С")
print(f"Количество аварийных замеров: {emergencies}")
```

2. Краткие теоретические сведения
Модуль: отдельный файл с расширением .py, содержащий определения функций, переменных и классов. Модульная архитектура обеспечивает повторное использование кода и декомпозицию сложных программных комплексов. Для подключения модуля используется оператор import module, для импорта отдельных функций — форма from module import function.
Точка входа __name__: при импорте модуля весь его код исполняется один раз. Чтобы отделить код тестирования от используемого функционала, применяется проверка if __name__ == '__main__':. Блок выполняется только при прямом запуске файла, но не при его импорте.
Системный модуль sys: предоставляет доступ к параметрам среды исполнения. Список sys.argv содержит аргументы командной строки: sys.argv[0] — имя запускаемого скрипта, sys.argv[1], sys.argv[2], ... — параметры, переданные через пробел при запуске. Это позволяет менять настройки программы без редактирования исходного кода.
Структуры данных: список (list) — упорядоченная изменяемая последовательность; кортеж (tuple) — упорядоченная неизменяемая последовательность; словарь (dict) — набор пар «ключ: значение» с уникальными ключами; множество (set) — неупорядоченная коллекция уникальных элементов.
Срезы: синтаксис [start:stop:step], где start — начальный индекс (включительно), stop — конечный индекс (не включительно), step — шаг. Отрицательные индексы отсчитываются от конца последовательности, а срез со step = -1 разворачивает последовательность в обратном порядке.
3. Задание (Вариант №1)
Вибродиагностика подшипников качения турбоагрегата. При выходе ротора газовой турбины на рабочий режим из-за износа подшипников возникает повышенная вибрация (мм/с). Высокочастотные помехи датчиков приводят к ложным выбросам, которые необходимо отфильтровать перед спектральным анализом.
Разработать модуль variant1_mod.py со следующими функциями: 1) filter_outliers(vibe_list, min_val=0.0, max_val=50.0) — отбраковывает замеры виброскорости вне допуска списковым включением; 2) get_stat_dict(vibe_list) — вычисляет среднее, минимум, максимум и объем выборки, возвращая словарь; 3) extract_top_vibes(vibe_list, k=3) — сортирует список по убыванию и срезом [:k] извлекает k пиков.
Разработать главный скрипт main.py, который считывает предел фильтрации из sys.argv[1] (по умолчанию 45.0), задаёт список замеров с выбросами, вызывает функции модуля и выводит отчёт.
4. Исходный код программы
Файл модуля variant1_mod.py:
def filter_outliers(vibe_list, min_val=0.0, max_val=50.0):
    return [v for v in vibe_list if min_val <= v <= max_val]
 
 
def get_stat_dict(vibe_list):
    if not vibe_list:
        return {'count': 0, 'mean': 0.0, 'min': 0.0, 'max': 0.0}
    mean_val = sum(vibe_list) / len(vibe_list)
    return {
        'count': len(vibe_list),
        'mean': round(mean_val, 2),
        'min': min(vibe_list),
        'max': max(vibe_list)
    }
 
 
def extract_top_vibes(vibe_list, k=3):
    sorted_list = sorted(vibe_list, reverse=True)
    return sorted_list[:k]
 
 
if __name__ == '__main__':
    test_raw = [10.0, -5.0, 30.0, 70.0, 20.0]
    test_clean = filter_outliers(test_raw)
    print(f"[Автотест модуля] Фильтрованный сигнал: {test_clean}")
    print(f"[Автотест модуля] Статистика: {get_stat_dict(test_clean)}")
    print(f"[Автотест модуля] ТОП-2 пика: {extract_top_vibes(test_clean, 2)}")
Файл главного скрипта main.py:
import sys
from variant1_mod import filter_outliers, get_stat_dict, extract_top_vibes
 
 
def main():
    max_limit = float(sys.argv[1]) if len(sys.argv) > 1 else 45.0
 
    vibe_raw = [12.4, 15.1, -99.0, 18.2, 520.0, 22.0, 41.5, 14.8, 48.0, 19.3]
 
    clean_vibe = filter_outliers(vibe_raw, min_val=0.0, max_val=max_limit)
    stats = get_stat_dict(clean_vibe)
    top_vibes = extract_top_vibes(clean_vibe, k=3)
 
    print("=== ВИБРОДИАГНОСТИКА ПОДШИПНИКОВ ===")
    print(f"Предел фильтрации (sys.argv): {max_limit} мм/с")
    print(f"Исходный объем замеров: {len(vibe_raw)}")
    print(f"Очищенная выборка: {clean_vibe}")
    print(f"Статистика: {stats}")
    print(f"ТОП-3 критических пика (срез [:3]): {top_vibes}")
 
 
if __name__ == '__main__':
    main()
